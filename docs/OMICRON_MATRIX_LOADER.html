Voltage grids

Select a result such as --39_1.I(V)_mtrx. Keep it beside the matching _0001.mtrx parameter chain and the other acquisition channel files.

The loader validates every channel first, then creates collision-safe calibrated 3D waves in root, x/y axes in metres, a bias axis in volts, and a text table mapping channel waves, units, and source files. Acquisition and calibration information is stored in wave notes.

Current grid support is intentionally strict: voltage on Spectroscopy Device 1, one forward/up subgrid, one repetition, and no ramp reversal. Unsupported layouts stop with an explicit message.

Z topography folders

Each acquired scan direction becomes a separate root:DataN wave. Trace/retrace direction, local pixel-centre coordinates, calibration, source path, acquisition parameters, and incomplete-scan status are stored in the wave note. Unacquired pixels remain NaN. File_Name and a collision-safe TopoSourceFilesN list map output waves to their files; an older text list is archived first.

Independent spectra folders

Curves become collision-safe root:STSN waves with voltage scaling and the recorded calibrated signal unit. Trace and retrace are kept separate. File_Name and STS_SourceFiles map the latest successful batch; prior text lists are archived.

Programmatic use

MatrixLoadGrid(filePath=path, biasAscending=1, flipX=1)
MatrixLoadTopologyGraph(folderPath=folder, includeRetrace=1, flipX=0)
MatrixLoadSpectra(folderPath=folder, biasAscending=1, includeRetrace=1)

Omit the path argument to use Igor's file or folder picker.

Integrity checks

  • Validates MATRIX magic, block bounds, parameter chains, dimensions, payload sizes, sample types, calibration, and output names.
  • Preserves incomplete acquisition geometry and marks missing samples as NaN.
  • Rejects unknown multi-curve, interleaved, or unsupported reversal/repetition layouts rather than guessing.
  • Runs entirely in Igor Pro 9; Python is not required at runtime.
